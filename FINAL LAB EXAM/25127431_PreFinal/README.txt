* Hệ điều hành đã kiểm thử: Windows 10 / 11 (64-bit).

* Trình biên dịch: MSVC (Microsoft Visual C++ Compiler) - Phiên bản tích hợp kèm IDE Visual Studio 2022.

* Lệnh biên dịch và Cách chạy:

1. Mở file solution (.sln) bằng Visual Studio 2022.

2. Nhấn tổ hợp phím Ctrl + B để Build project.

3. Nhấn Ctrl + F5 để chạy chương trình.
